# TERMINAL ZINE

**A haunted hypertext zine for ghosts, worms, and soft errors.**

Terminal Zine is a retro-future HTML project styled like a dead BBS that's still processing packets. Built entirely with HTML and CSS (no JavaScript), it simulates a cracked bootloader into a fictional archive of glitch philosophy, body horror, and broken identity.

## 💾 Features

- CRT-style homepage styled in Share Tech Mono
- 5 public articles with full comment threads from simulated users
- 1 hidden sixth article (`article06.html`) with no index or backlinks
- Custom user personalities speaking in Ballardian and Burroughsian tones
- No JavaScript, no frameworks — just handcrafted weird HTML
- Fully responsive with consistent retro layout across all pages
